# audit/ —— 审计文件目录（自 2026-11-10 起所有审计文件放这里）

## 命名规则
| 文件 | 含义 |
|---|---|
| `AUDIT-REPORT-<版本>.md` | **外部/独立审计报告**（如 v2.0.0 / v2.3.0 / v2.3.1） |
| `AUDIT-SELF-<版本>.md` | **自审计报告**（如 v2.4.0） |
| `AUDIT-RESPONSE[-n].md` | 对审计的逐条回应与修复记录 |

## 流程约定
1. 新审计报告一律放本目录，文件名带被审版本号；
2. 回应文件同目录、同前缀（`AUDIT-RESPONSE`），必须逐条给出「核验结论 + 修复动作 + 复算证据」；
3. 发布版本若随包附带审计材料，从本目录复制（不移动），文件名保持一致；
4. `docs/` 只保留项目文档（COUNTS / V3-STATUS / SESSION-HANDOFF / 结构说明等），不再放审计文件。
