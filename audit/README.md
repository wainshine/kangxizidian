# audit/ —— 审计文件目录（自 2026-11-10 起所有审计文件放这里）

## 命名规则
| 文件 | 含义 |
|---|---|
| `AUDIT-REPORT-<版本>.md` | **外部/独立审计报告**（对被审版本的当时记录） |
| `AUDIT-SELF-<版本>.md` | **自审计报告** |
| `AUDIT-RESPONSE[-n].md` | 对审计的逐条回应与修复记录 |
| `AUDIT-VERIFICATION-LOG.md` | **核验台账**：各轮审计声明的复核结论（真/部分真/未证实）与当前去向 |

## 流程约定
1. 新审计报告一律放本目录，文件名带被审版本号；
2. 回应文件同目录、同前缀（`AUDIT-RESPONSE`），逐条给出「核验结论 + 修复动作 + 复算证据」；
3. **审计记录不改写**：外部报告与历史回应保留原文；后续变化用顶部「记录状态」标注 + 文末「后续落实状态」追加，
   核验结论写入 `AUDIT-VERIFICATION-LOG.md`；
4. 发布包需要附带审计材料时从本目录复制（不移动），文件名保持一致；
5. `docs/` 只保留项目文档，不再放审计文件（见 `docs/README.md`）。
