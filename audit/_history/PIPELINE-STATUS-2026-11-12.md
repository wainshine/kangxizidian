## 2. 本轮根因收敛（三条，互相独立）

1. **切框来源错误**：历史 mapping box 是「字内墨迹紧框」→ 面积随字波动（中位 88×88，p5–p95 78–98，±20%）；
   这就是「左边切大一圈、右边漏一半」的直接来源。
   → 已改为 **block-based mapping**：box = 2×2 格块 ∩ 版框正文区。
   实测：框宽 p5/p50/p95 = **99/102/103**，框高 **95/98/100**，同页标准差中位 **0.43px** —— 面积口径统一。
2. **页级格点/正文区质量**：少数页面上 block 相位/正文区边界仍不准 → 框线残留/字身被裁；
   需按页校验（block 是否包住字身墨迹、quad 边是否压线），失败页整页修格点/正文区，**不按字修**。
3. **mapping 指派错误**：约 35 字（如 愈/匸/閧/而）的裁片内容与标签不符（裁片里是小字注文/邻字），
   这类只能靠 mapping 层审计修正标签，不是裁切问题（旧 v2.5.8 靠 overlay 掩盖，重新出现）。

## 3. 当前候选（v2.7.0 候选，不发布）

- 结构：block-based mapping + 切前排除框线；**无 restore/overlay 层**；
- 全量重建：QA PASS；内容闸 vs v2.5.8 = **35 字**；框线逃逸扫描 = **60 字**（均为上述 2/3 类）；
- 「块内贯穿线删除」规则实测会误伤伸出块外的字身（内容闸 35→60），已撤回，改为仅在格点校验通过的页启用。

## 4. 下一步（类级，不再单字）

1. 页级校验闸 `check_page_geometry`：
   - 同页 block 宽/高恒定（已满足）；
   - 每字 block 是否完整包住主字簇（墨迹越界率 <1%）；
   - quad 边界 8px 内是否存在贯穿线（有则整页收紧 quad，并记页级修复日志）；
2. mapping 指派审计：裁片内「2×2 块含 ≥2 个独立小字/主簇」→ 标为 assignment_error，交 mapping 层修正（不改字形）；
3. 通过后在验证页启用块内贯穿线规则，重建、四闸（内容 0 / 框线 0 / 缺件降 / 目检）全过才发布。
