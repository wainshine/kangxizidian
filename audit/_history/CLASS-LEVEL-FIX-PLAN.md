# 类级修复方案（v2.4.16 基线）  [2026-11-11 08:55]

> 原则：**不再「owner 圈一个 → 隔离一个」**。每个缺陷类 = 一个检测器 + 一个管线级修复 + 一个类级验收指标。
> 所有改动默认关闭（opt-in），未通过消融验收不得进入发布管线。

## 1. 缺陷分类（来自 owner 标记 38 字 + 全库扫描）

| 类 | 定义 | 典型 | 现有检测 |
|---|---|---|---|
| A 外来墨 | 字框内混入非本字墨迹：碎片/邻字/注文/框线残片 | 路 的「[類篇]」残片 | 参考结构闸（v1 小碎片；v2 配准+结构失配） |
| B 缺笔 / 框错 | 本字笔画被裁掉；或框没框住字 | 像/娘/胂 缺部件 | 反向覆盖（参考有墨我们无）+ 结构失配 |
| C 框线合并 | 版框/引用框直线与字形主轮廓合并，轮廓级删不掉 | 佇、埳、婀、篦、警、靀、𨹞 | 细长直线组件（fitLine）全库扫描 |
| D 位偏/缩放 | 碎片/邻墨把整字拉偏、缩小 | owner 圈出的偏小字 | 主簇 bbox 归一 |
| E 错字/结构失配 | 标签与墨迹结构不符 | 娘/胂/榑 | 参考结构闸 v2（major） |

## 2. 类级修复（已实现，opt-in）

| 修复 | 对应类 | 开关 | 消融结果（保真度：owner38 / 随机200） | 结论 |
|---|---|---|---|---|
| 主簇 bbox 归一 | D | `normalize_main_cluster` | 0.667→0.694 / 0.720→0.732 | **正向，待采纳** |
| 像素级参考过滤（组件级删除） | A | `enable_ref_filter` | 0.667→0.657 / 0.720→0.702（标定 dilate25/cov0.2） | 配准漂移，**需改多部件配准** |
| SWT 细直线像素删除 | C | `enable_line_swt` | 0.667→0.208 / 0.720→0.224 | **误删细笔画，禁用** |
| 轮廓级直线删除（已有） | C | postprocess | 6 字形确认（埳/婀/篦/警/靀/𨹞） | 仅能处理分离轮廓；合并轮廓无效 |

## 3. 类级验收协议（必须先过再重建）

评测集：**owner 标记 38 字（阳性）** + **200 随机字（阴性）**，指标：
1. owner-38：每类检出率（该类的至少一个特征命中）与修复后保真度；
2. 随机 200：**回归率 <2%**（保真度下降 >0.01 视为回归）；
3. 全库预抽 500 字：字形 vs 原书墨（参考支持域内）配准 IoU 不下降。

未达标 → 不重建、不发版。

## 4. 下一步（类级顺序）
1. A 类：把参考配准从「最大组件」改成「所有显著组件的联合 bbox」，重测消融；
2. C 类：轮廓级「长直线+90°折角」判定，只删非主轮廓且直线度 >0.95 的轮廓；
3. B/E 类：反向覆盖 + 结构失配联合判定，输出「框错/缺笔」清单（自动重定位队列）；
4. D 类：采纳主簇归一（已正向）；
5. 全部通过 → 全库重建（cache tag 升级）+ 类级统计报告 + v2.4.17。
