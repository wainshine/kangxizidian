# PLAN v2.6 · 从「能生成」到「可签收」的修改方案

> 现状基线：v2.5.5（17,007 字，2×2 格块掩膜 + 版框擦除 + 双闸）；
> 依据：两轮外部审计 + 我方对抗性回应（`audit/AUDIT-REBUTTAL-v2.5.4.md`）中的已知债与门禁缺口。
> 原则：**先修一致性/可复现，再修质量，最后回收覆盖率**；每阶段带机器验收线，不过线不进入下一阶段。

---

## 阶段 0 · 一致性与门禁（v2.5.6）✅ 已完成 2026-11-12

> 目标：消除「全量重建会回滚修复」「门禁靠人肉」两处高危。

### 0.1 修复回写（最高优先，高危）
**问题**：v2.5.3 的 1,109 字缺部件修复 + v2.5.4 的 347 字切偏修复只改了 TTF，未回写 mapping/cache；
任何全量重建都会静默回滚这些修复。

**方案**：
1. 新增 `work/lead/repair_ledger.jsonl`：每次修复落 `{char, page, half, old_box, new_box, contours_sha256, script, version}`；
2. 历史修复可重建：从 `missing_scan_v252b.jsonl`（1,109 候选）与 `offset_scan_v253.jsonl`（825 候选）
   重跑两套 repair 脚本的**候选构造逻辑**（不写 TTF），把「通过逐字 gate 的子集」的 contours 落 ledger；
   与现 TTF 逐字比对 sha 校验 ledger 完整性（期望差异=0）；
3. `font_build` 增加 `--repair-overlay <ledger>`：按 `(page,half,char)` 优先使用 ledger 轮廓；
4. 用 `mapping_v256 = mapping32 + 修复框` + `--repair-overlay` 全量重建 → 与 v2.5.5 逐字对比；
5. 打包 v2.5.6。

**验收（硬）**：
- 重建字体与 v2.5.5 逐字 sha 对比：差异 **0**（允许字序/时间戳差异，不允许轮廓差异）；
- `content_loss_gate v2.5.5→v2.5.6` = 0；QA PASS；DOC-CHECK PASS；
- `build_recipe-v256.json` 随包且含 ledger sha。

**风险**：ledger 无法完整复原（内联校验数据未落盘）→ 备份方案：从当前 TTF 提取这些字的轮廓反向写入 ledger（TTF 即真值，可信度等同发布物）。

### 0.2 发布门禁脚本化
新增 `scripts/release_gate.py`，一条命令串联并输出 `gate-report.json`：
```
font_qa → content_loss_gate（含覆盖率下限）→ manifest 字符集 diff →
scan_missing_parts（按版本可全量/抽样）→ stamp_version 校验（内部版本==发布版本）→
check_release_docs → font_package（SHA 最后）→ zip 自检
```
**验收**：v2.5.6 的 gate-report 全绿；任意一项 FAIL 则打包中止。

### 0.3 字符集差集 + 门禁诚实性
- `content_loss_gate` 增加 manifest diff：`removed` 必须全部出现在 `quarantine` 清单，否则 FAIL；
- `font_qa` 增加「字体内部版本 == manifest.version」硬闸（不再只查内部自洽）。

## 阶段 1 · 质量收敛（v2.6.0，约 1.5 天）

### 1.1 主成分归一化（P1-B 根治）
**问题**：杂物/框线残段入字形后撑大 ink bbox → 归一化后字身整体缩小 20–30%（挕/垂 类）。

**方案**：`normalize_main_cluster=True`（现成参数，默认关闭）：
- 归一化 bbox 改用「主簇 bbox」（面积≥22% 最大组件者并集）；
- 先做**消融评测**再默认开启：owner-38 缺陷集 + 300 随机字；
- 验收：owner-38 中「缩小类」改善 ≥80%，随机 300 字回归 <2%，content gate=0。

### 1.2 杂物入字诊断闸（与内容闸对称）
新增 `scripts/scan_intruders.py`：块边 10% 带内 + 线状/注文尺寸特征组件 → 台账；
与 refgate「多余杂物」合并为 `intruder-ledger`；仅对**台账命中**的字做外科清理（不重扫全库启发式）。
**验收**：random120 目检脏字率从当前 4–7% 降到 **<1.5%**；content gate 保持 0。

### 1.3 残余框线/碎片专项
- 轮廓级判据：近轴长直线段 + 90° 折角 + 与主轮廓不连通 → 删；
- 仅作用于 intruder-ledger 命中字；owner 100 字表回归。

## 明确「不做」清单
1. 不再引入「按尺寸/位置删组件」的全局启发式（v2.4.16–19 的 P0 教训）；
2. 不在无 content-gate 的情况下做任何全量重切；
3. 不为覆盖率回收「不确定字」——宁缺勿错（D15）；
4. 不在单字层面打补丁代替类级扫描（除非 owner 标记驱动且入回归集）。
