## 4. 结论（§3.0 判读分支）

**precision 0.925 ≥ 0.8 → 走 §3.1-§3.4（页码标定 + 紧窗 DP）。**

- 交接 §3.0 的第一成因假设（「检出 precision 低」）被实测**推翻**：
  历史 0.42-0.43 是 v1.6 裸输出（PROBE §8 口径），§3.0 过滤器栈（方形度硬闸+触边+结构臂）
  把 precision 推到 0.86-0.99。FP 需由 DP 记账消化的假设降级为「残余 7 框记账」。
- 生产过滤器配置 = **G′**：①触边降级为标记不杀（杀 16 个真字头：丁头/古文丁/念/恰/怠等）；
  ②保留严格 h/blobs/方形度；③版框闸只用**原墨 ≥300px 竖线段跨越**
  （page_stats 版框与实测线不符：13_0163 实际框缘 x=51/1824，page_stats 说 80/1767，
  越界检查误杀 6 个真字头，废弃）；④标题块/透印半版两臂。
- 残余 FP 7 个：增字圈 ×2（新 FP 类：印刷圆圈+增字，可加圈检测或 DP 记账）、
  04_0030 注文双字竖排粘连 ×5（80-95px 达字头尺寸，blob 判据分不开——若 DP 记账不够，
  再上字头/注文分类器，即 0.5-0.8 分支的工具）。

## 5. 勘误与新发现（r10，本实验顺带产出）

1. **rule_xs 死代码**（所有者核验属实）：`page_ink()` 先减长线 → `rule_xs(残墨)` 恒空。
   v1.6 的 `clip_to_column` 从未生效（PROBE §8 已加勘误，T1 门不受影响）。
2. **01_0006R = 目录透印半版**：内区墨占比 0.061（正常 0.148-0.194），其 5 框全伪。
   HEADWORD-COVERAGE「每部首页 2 个标题大字」需勘误——实为 L 半版九字标题块 + R 半版透印假象。
3. **总目无每部起始页码**：PDF01 p4=空白扉页，p5=部首总目（只有部名+画数）。
   **§3.2 原公式（目录页码−书眉页码）前提不成立**，改用**书眉自标**：
   每页自带（集名/部名/画数/页码），条目窗口由相邻页的（部,部外画数）切片界定，
   配合 entry_sequence 单调性——比目录算术更强，§3.2 按此重设计。
4. ~940px 处竖线 = **书口折缝阴影**（非印刷线），不得当框界（原墨无 ≥300px 连续段）。
5. 一部首页裸「一」字头（横条 ~109×15）低于细笔画兜底的 h≥30 门槛，**从未被检出**——
   DP 对账时一部第 1 条会空位，需细笔画分支补（h≥30→h≥15 仅限横扁字）或 DP 空位容忍。
