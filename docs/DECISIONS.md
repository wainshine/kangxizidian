## D7 · 版面口径（2026-11-07，实测定稿）

- 扫描单位：1 PDF 页 = 1 跨页 = 左右两版；每版 **~19 列单行注文小字**（列距 ~47px，
  列间**无印刷栏线**——叠加图视觉实证，02_0029 右版；不同页 14-19 列随密度浮动）；
  **字头大字（66-90px）内嵌跨列**，不为一列所拘；注文 h0 = 37px；字头/注文高比 2.08
  （1.95-2.19，金标实测）。此前「2 列」「8 列」「14 列单行/双行」「界栏 135px」
  「2.2-2.6 倍」诸说法一律作废（各为不同页/不同尺度的误读）。
- 圈号（○ 内含数字）= 序号/音序标记；【】六角括号 = 引书名（双行夹注）——均非字头。
- 书眉 = 每版外缘「康熙字典/集名/部首/页码」，逐页真源。
- 书内页码 = 2×扫描页 − 册内偏移（PDF01 偏移 11 已实测；**每册偏移表 T2 产出**，
  此前两处各说一半的写法以此条为准）。
- kKangXi 页码是通行影印本体系，与本书扫描页无固定倍数，只作字符集上界。

- **不数孔洞/连通分量**：刻本为雕刻会把笔画刻断，孔洞缺失、连通分量偏多、碎片都是工艺特征，
  不得作为字形质量判据。`font_qa` 已删除孔洞对照与连通分量/碎片 soft flag；
  字形级框线检测用线段几何（细长直线 ≥0.5 字宽、厚 ≤3px），不用孔洞/连通性。
- **参考字体只做对比分析**：不得据此自动删改字形组件（与 D20 一致：破坏性清理开关在主链 raise）。
- 覆盖事实：对 17,007 字集，霞鹜文楷覆盖 12,427（73.07%），高于旧系统宋体 TC 12,155（71.47%）。


## D22. 三闸接入与 strip_border_lines 过渡口径（2026-11-12）

- **三闸必跑**：`glyph_frame_gate`（TTF 输出字形扫细长直线）、`provenance_gate`（manifest/mapping/stats 自洽、无拷贝通道标记）、`page_geometry_gate`（quad 覆盖/box 坐标变换/空指派/块∩quad）接入快闸与全闸；glyph_frame 判据只用线段几何（D21），不做孔洞/连通分量判定。
- **strip_border_lines 过渡**：它与「pre-cut」不变量冲突，但 200 字 A/B 量化（`work/lead/strip-border-ab-v4.json`）显示当前页面几何下它仍在清理块边界界行/框线残段（改动 56/200 字、11,263px；仅 2/200 改变轮廓数）；页面级 frame mask 对样本 0 作用，块边带 pre-cut（3px）会误删真笔画（53/200 差异）。
- **决策**：CS1-B 重建**暂保留** strip；CS2 先修页级几何（343 无 quad/184 半版/box 越界 198）由 pre-cut 承担，再按同一 A/B 复测后**摘除** strip，验收 = `glyph_frame_gate=0` + 内容/缺件闸无回归。摘除前不得宣称「纯 pre-cut」，也不得新增任何「切后擦」用途。
