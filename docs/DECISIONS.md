## D2 · 家族名（2026-11-07，沿用 PROMPT）

`KangXi Kai`（康熙楷）。Kai 指**字头**风格（楷体，带锋）；注文为宋体，本项目不使用其字形。
OFL 1.1，不得使用 LXGW 的 Reserved Font Name（霞鹜/霞鶩/落霞孤鹜/落霞孤鶩/LXGW）。

## D3 · 覆盖边界（2026-11-07，T0.0 门判定后确立）⭐

**T0.0 门判定：不过**（`docs/HEADWORD-COVERAGE.md`）。据此固定项目边界：

```
real 真迹：约 17,000–18,600 个康熙字头（confidence: medium，T2 全书部首序对账后转实测值）
cmap 覆盖：20,992（基本区）+ 42（标点/数字/空格）= 21,034
缺口构成：简体新码点、日文新字体、现代造字 —— 1716 年字典中本无字头
```

- **「20,992」是 cmap 覆盖承诺，不是真迹承诺**。禁止用「覆盖率 100%」表述真迹数量。
- 验收表（PROMPT §9）的「覆盖率 20992/20992」改读为「**cmap 覆盖** 20992/20992，
  其中 real ≤ 18.6k，其余为 mapped/gan/ribbon_fb，逐字 provenance 可查」。
- 缺口处理按 PROMPT §4.1：GAN 生成 / ribbon 回落 / 简体码位映射繁体，**不冒充 real**。

## D7 · 版面口径（2026-11-07，实测定稿）

- 扫描单位：1 PDF 页 = 1 跨页 = 左右两版；每版 **14 列单行注文小字**（列投影白谷计数实测，
  所有者独立复核一致）；注文 h0 = 37px@150dpi；字头 77px（方正）；**字头/注文高比 2.08**
  （1.95–2.19，金标实测）。此前「2 列」「8 列」「2.2–2.6 倍」的说法作废。
- 书眉 = 每版外缘「康熙字典/集名/部首/页码」，逐页真源。
- 书内页码 = 2×扫描页 − 册内偏移（PDF01 偏移 11 已实测；**每册偏移表 T2 产出**，
  此前两处各说一半的写法以此条为准）。
- kKangXi 页码是通行影印本体系，与本书扫描页无固定倍数，只作字符集上界。

## D8 · 页面形变纠偏（2026-11-07，所有者建议参考 vModou）

采用 vModou（MIT）思路的自动化重实现（`scripts/t0_rectify.py`，未复制其代码）：
强横线端点定四角 → 透视拉正 → 合理性检查失败即跳过。**几何拉正 8/8 成功 ≠ 检测收益**
（1 赚 2 亏 1 平，重采样伤细笔画）；T1 对 orig/rect 做 A/B 择优，弯曲重的版优先 rect。

## D9 · T1 门槛（2026-11-07，审计 #2/#3 采纳）

- **分层金标**：主卷正文 ≥30 框、补遗/备考 ≥15 框，两组分别报 precision/recall/IoU，
  **任一层不过即停**（当前 53 框中主卷仅 23，需扩充）。
- **IoU 之外两条硬判据**（防并格/空格，guangeti C 线错标 11.5% 的教训）：
  ① 框内墨团数：按标准横向闭运算后，高度 ≥0.4×框高的子块数必须 =1（防一格两字；
     「二/三」类多横画字头子块高仅 ~0.13×框高，不受影响）；
  ② 墨迹不触框边（边距 >2px）。
- **金标状态**：provisional（AI 目检）。所有者抽检 ≥20 框、错框 ≤2 后方可作为 T1 放行依据。
