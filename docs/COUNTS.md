## 归因（本会话取证）

1. **不是正典多计**：01_0060/0085/0100/0115 人部页人工 truth（候选裁框目检）= 7/17/18/13-14，均 ≫ strict；正典 人部 844 与目检密度一致。
2. **不是检测漏框**：detector 对 人部 71 页做原墨分量覆盖检查，0 未覆盖；字头都进了候选，只是**分类分数被压低**。
3. **是分类阈值问题，且与字形生僻度强相关**：生僻/复杂部首（魚鳥水艸心）漏 20-32%；常用简单部首（一丨…）±2%。证据：12_0100 魚部 strict 15，目检 18-20，被漏者全是 hw 0.5-0.8 的大字真字头，而 FP 是 sr 1.4-1.6 的注文两字块。
4. **结构性误差**：卷首正文跨页的 R 半版 = 卷扉页续（部首清单）不是正文；14/36 卷末 L 半版留白。solver 的 body 半版序列要用 `docs/STRUCTURE.md` 口径（≈6,479 半版）。

实现要点：① 候选框取 hw≥0.5 的大字框（跳过注文块）；② 相邻框归一化 40×40 NCC；③ 每部内重出块位置从 canonical 已知，做一维匹配（句子的「重出模式」对齐）。

## 十二、字头 OCR 漂移校正实验（2026-11-08 22:00）——**未达预期，不采用**

新增资产：**`work/lead/hw_ocr.jsonl`** —— 全量 42,324 个字头候选的 PP-OCR 识别结果（`{page,half,idx,box,text,score}`；大字形 OCR 在 demo 28 字形上实测 **19/28=68% 精确**，高分行多在 0.8+）。
新脚本：`scripts/lead_hw_ocr.py`（5 进程 4 分钟）、`scripts/lead_drift_fix.py`/`lead_drift_fix2.py`（每半版 δ 估计 + 部内平滑拟合 + EM 两轮）。

**做法**：δ = 使 `canon[ci_mapping+δ]==OCR 文本` 的偏移；部端点强制 δ=0（部总量精确）→ 平滑 → c'=c+Δδ。
**实测结果**：
- δ 估计可用（例：05_0017R 真偏移 −11 → 估计 −11 ✓；04_0017R +5 → +5 ✓；03_0027R 0 → −1 ✓）——方法本身正确；
- 但全量高置信 δ 只覆盖 506-2,529 个半版（OCR 文本错误 + 单半版观测少），部内平滑后 **δ 曲线噪声大**；
- 用 v6 计数重跑映射后，demo 28 字形位置偏差 **不降反升**（v5 median 5.5 → v6 11.0）→ **不采用 v6，counts_v5 仍为基线**。

**结论**：自动逐页计数校正到此为止。剩余可行路线只有：
1. **人工校准**（每卷抽 5-10 页核字头数，反推部内分布；detector 也建议校 10% 页可压到 ±1-2）；
2. 更高分辨率扫描/活字级配准（超本项目数据条件）；
3. 接受 ±5-36 的漂移，只在**可验证窗口**（owner 金标附近页）产出可信字形。

## 十三、唯一字 OCR 锚点 + 迭代精修（2026-11-08 23:00）——**部分有效，未过闸**

新发现：**PP-OCR 识别的字头文本中，若该字在正典全序列里只出现一次**（生僻/扩展区字常见），则它的正典位置是唯一的 → **精确锚点**。全量 42,324 个字头 OCR 结果中提取出 **6,886 个「唯一字锚点」**（|δ|≤120 过滤后 3,831 个，覆盖 2,653/6,496 半版，δ 中位数 0、p10 −31、p90 +26）。
新脚本：`scripts/lead_refine_delta.py`（迭代：唯一字锚点 → 逐半版 δ 中位数 → 部内 Huber 平滑 LS → 校正计数 → solver 重建 mapping → 重复，单页修正上限 ±3）。

**实测（4 轮迭代）**：
- owner 金标位置偏差明显收敛：宵/怔/昴/昵/時/曀/班 → **0**、況 +3、泄 +4、駮 +8；仅 怒 仍 −28（个别页被错误锚点带偏）；
- 但 **验收闸仍 FAIL**：owner 框 IoU 命中 0/11、dup-pair 0.218 vs 随机 0.192、**覆盖率掉到 69.8-76.8%**（校正后部分半版计数超过候选可用数，被 solver 判为未指派）。

**根因**：唯一字锚点有假阳性（OCR 把常见字形误识别为某个全局唯一的生僻字 → 该字位置远在他处），Huber 平滑无法完全剔除；且「部端点 δ=0」的强约束与个别错误锚点冲突，导致局部 δ 摆动过大。
**结论**：这是目前对 owner 金标最有效的自动校正（多数偏差归零），但**仍不足以过闸**；若继续，应做「锚点可靠性分级”（要求同一半版 ≥2 个一致锚点、或与相邻半版 δ 连续性检验）后重跑。当前**仍以 bu_v5 映射为最佳基线**。
