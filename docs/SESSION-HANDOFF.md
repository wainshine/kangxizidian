## 3. T2 收口操作清单（**§3.0 决定性实验必须最先做**，其结果决定后续走哪条分支）

### 3.0 决定性实验（~1h，先于一切）：字头专有过滤器的 precision

审计结论（采纳）：T2 卡点的第一成因是**检出 precision 低**（FP 吃掉序列槽位、
OCR 误读在宽窗里乱配），页码标定只解决位置、不减少 FP。先量出过滤器能让
precision 到多少，再决定走哪条路：

```
取 一部（条目少、边界清楚）
  → 过滤器：高≥1.5×h0 + 界栏内 + 不触边 + 墨团数=1 + 方形度 0.7-1.4
  → 对该页全部检出框人工判「字头/非字头」，量 precision
判读：
  ≥0.8  → 走 §3.1-§3.4（页码标定 + 紧窗 DP）
  0.5-0.8 → 先做字头/注文分类器（特征：高度、密度、位置、双行结构），DP 延后
  <0.5  → 放弃整部 DP，改「页内定位（页码锚点）+ 页内计数校验」
```

precision 的量化目标与现状：金标页实测 0.42-0.43（逐页 0.17-0.8）；FP 构成 =
书眉标题字、部-header、注文粘连块、圈号、边角料（所有者 r8 五类命名）。

## 4. 关键技术事实（血泪浓缩，违反即返工）

### 版面（150dpi 口径）
- 1 PDF 页 = 跨页扫描 = 左右两版；内容页 922×786pt 横版，*_0004 类 = 目录/封面（竖版）
- **~19 列单行注文小字（列距 ~47px，列间无栏线）**，字头大字跨列内嵌（叠加图实证；
  不同页 14-19 列随密度浮动；此前 63px/135px 两说均为片面测量）
- 字头框：高 66-90px、宽 85-110px（大型复合字可 115×145）；注文小字高 37px（h0）
- **切格约束 = 不跨界栏 + 不含注文行**；宽高死数字上限作废（DECISIONS D7/D9）
- 书眉（每版外缘竖排）：康熙字典/集名卷次/部名/鱼尾/**页码（68-84% 高度）**
- 圈号=圈发标记非字头（#54 已移金标 errata）；【】=书名引用；⭕序号圈=序号

### 数据集（标签真源）
- `kx_full.xlsx` 48,708 条；**行序≠部首序**，必须重排（rad_i→stroke→原序）；
  重排产物 `work/t2/entry_sequence.jsonl`
- **笔画=总笔画语义**（角7/金8/馬10/呢8）；书眉画数=部外笔画；桥：dataset = 画数 + 部自身笔画
- 214 部首表注意：含 戶（非户）、靑（非青）、隹、雨（初版漏隹雨两部）
- 数据集有实证漏洞：玄字部缺「玄」（玄是第 95 部首）——参照用，不作真源

### 切格器 v1.6（`scripts/t1_segment.py`）
- 尺寸闸 = 1.5×h0（h0=注文高度众数，≈37）；THIN_PAGES（一/丨/丶/丿/乙/亅部页）才启用
  细笔画兜底，其他页启用=放注文粘连块进来
- 管线：erode(5)→dilate(18) 提议 → refine_v3（种子内50%区+多数归属生长，核15×15）→
  方形度补并（合并后 0.7≤宽高比≤1.4 且高比 0.6-1.4）→ NMS → 界栏裁剪 → 纵向白隙修剪
  → h>100 最大墨量窗收缩 → 硬判据（墨团数=1）+ 密度闸
- precision 0.42-0.43（FP=书眉标题字/部-header/注文粘连）→ **设计内由 T2 记账消化**
- 金标协议：AI 提框 → 3× 网格逐框自检 → 所有者裁决；**sheet 级目检废弃**（漏检率 25%+）

### 工具坑（每条都踩过）
- 依赖装进项目 `.venv`（python 3.12），**不要用 `uv run --with`**（pypi CDN 慢到卡死）；
  装包用 `--index-url https://pypi.tuna.tsinghua.edu.cn/simple`
- cv2 5.0：非连续切片会段错误（`.copy()`）；空数组进 connectedComponentsWithStats 段错误（加防护）
- numpy int32 直接 json.dump 会炸（坐标强转 int）
- `v[:, -0:] = 0` 会清空整个数组（cut==0 时跳过）
- PIL 画中文必须 ImageFont.truetype('/System/Library/Fonts/Hiragino Sans GB.ttc')
- BSD grep 的 `\b` 不可靠；zsh 里 `echo ===` 会报错；awk 字符类转义易炸
- shasum 大文件放后台；页数统计等批量操作放后台 + TaskOutput 等待
- 并发 ≤10 线程（cv2.setNumThreads(1)、OMP=1）
