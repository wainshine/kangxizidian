## 1. 一句话

刻本 12 集×3 卷的**卷↔部首映射与 MIT 数据集 path 的集名划分 100% 一致**（214 部首恰好各归一卷），

## 3. 卷扉页版式（实测）

- 每卷首页前有 **1 个卷扉页**（少数卷跨 2–3 个半版）：版式为竖排、自右向左：
  `康熙字典` → `X集上/中/下` → 部首**笔画组标题**（如「一畫」「二畫」「三畫」）→ **部首列**
  （每列「X部」，常附异体注：人部「亻同」、尢部「兀元尢允同」、艸部「艹同」等）。
  扉页只列该卷部首；**列表可能省略末尾 1–4 个部首**（如子集上省略二亠、寅集上省略屮），
  省略部分不改变卷界判断（卷界只由「首部部首」确定）。
- **扉页阅读序 = 全书阅读序（每跨页先 R 后 L）**；扉页可跨页，其最后一段常印在
  **该卷首页（正文第一跨页）的 R 半版**，该页 L 半版才是正文首页。实测例：
  - 子集上：扉页 p5L（一丨丶丿乙亅）+ 续 p6R（二部/亠部），正文从 p6L 开始；
  - 寅集下：扉页 p161L（干幺广廴廾弋）+ 续 p162R（弓彐彡彳），正文从 p162L 开始；
  - 巳集中：扉页 p151L（火爪父爻爿片）+ 续 p152R（牙），正文从 p152L 开始；
  - 子集下：扉页跨 3 半版 p128L → p129R → p129L（20 部首），正文从 p130L 开始。
- 卷扉页总目录：PDF01–12 各卷扉页 = `work/seq/structure/{fm_*,head_*}.png`。

## 4. 部首页问题（Lead 问 p143/144）

- **部与部之间没有独立扉页，直接接排**（同一跨页内 R→L 或接下一页）。
- 每个「部首页」是**部首自字版**：该版在版心写「X部」+ 画数字段，正文顶部以大字形印
  部首自字（及古文异体），其后接部内条目；它不是独立扉页、不单独占页。
  例：p5L=子部首页（子+古文）、p15L=宀部首页、p162L=干部首页。
- **PDF01 p143/144 无 title 页**：p143 是八部正文页（版心：子集下/八部/六畫 七畫，即跨
  五畫→六畫分界），p143R/p144=八部正文，大字为字头（典/龏/谷…）。Lead 目检到的
  「title 类大字形」= 正文大字头或版心画数字段，不是扉页；唯一插入式扉页是**卷扉页**，
  它可能落在卷首正文跨页的 R 半版（见 §3），视觉上像「正文页里出现大标题」。

## 5. 卷界半版级版面规则（solver 记账用；实测 `work/seq/volume_layout.json`）

- **卷首跨页**：R 半版 = 卷扉页尾/留白（100dpi 墨率实测 0.037–0.079，远低于正文 0.13–0.22），
  L 半版 = 正文第一半版。→ 每卷第一页只贡献 L 半版正文。
- **卷末跨页**：R 半版 = 正文最后一版；L 半版在 **14/36 卷**留白（墨率 0.000–0.004），
  其余 22 卷 L 半版也有正文（卷恰在叶界处收束）。
- 中间跨页两半版均为正文；部首页亦然（两半版都是正文）。
- 据此估算正集正文半版总数 ≈ **6,479**（=Σ[每卷 2×页数 − 首页 R − 末页 L(若空)]），
  对应 42,302 条 ≈ **6.53 条/半版**；该数可作 solver「累计半版计数」的全局上界校验
  （实现见 `scripts/provenance/volume_structure.py`/`volume_layout.json`，阈值 0.08/0.06 为 100dpi 墨率）。
- 已知噪声：卷界前有 blank/cover/牌记页 2–8 页（`page_roles.jsonl` 的 blank/cover/title_page），
  不属正文；`volume_sections.json` 的 runs 是页级区间，把卷首跨页 R 半版（扉页尾）也算进了
  「body 页」，按半版记账时应扣除（每卷 1 个半版）。

## 6. 与 `work/lead/volume_sections.json` 对照

- 卷序一致（子→亥 × 上/中/下）、卷界页与扉页实测一致；本文件 body_pages 直接用其 runs。
- 需要修正/注意的 3 点：
  1. runs 是**页级**区间；卷首页的 R 半版是扉页尾（非正文），solver 半版记账要扣；
  2. 14 卷卷末跨页 L 半版留白，solver 不能把该半版计入正文计数；
  3. `06_中` 的 run 起点 151：p151 本身是卷扉页页（L=扉页），正文实际从 **p152 L** 起；
     其余卷正文从 run 起点页的 L 半版起（R=扉页尾）。
- 结论：volume_sections 可作 solver 基础，但**页级→半版级**转换必须按 §5 规则处理。

## 8. 残余风险

1. 卷扉页「末尾省略部首」使个别卷的**末部首**尚未逐字核（卷界由下卷首部部首闭合，不影响划分）；
   若需逐字全验，读出全部扉页续页（本文件 evidence 已给可复查页码）。
2. 半版级正文计数阈值（0.08/0.06）用 100dpi 墨率经验值，个别边界页可能 ±1 半版；
   精确值待逐页半版 OCR/计数（v3 solver）落实。
3. 卷末留白判断 14 卷来自墨率；建议 solver 用实际半版序列累计再核。
4. PDF13 分节页界来自书眉 OCR（部分页集名读数缺失，按单调性归段），±1 页可能；
   若需精确，用 13 册書眉全字段（部名/画数缺失，只有集名+叶码）逐页核。
