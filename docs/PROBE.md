## 2. 版面参数（实测，px@150dpi；300dpi ×2）

| 参数 | 实测 | 备注 |
|---|---|---|
| 扫描单位 | 1 PDF 页 = 1 跨页 = 左右两版 | 中缝白带可分；部分半版为透印空白 |

| 字头高 | **77 px**（72–81，金标 53 框） | 方正：宽 median 77 px |
| **字头/注文高比** | **2.08**（1.95–2.19） | 金标实测；PROMPT 猜 2.5–3 偏高（其口径含粘连框） |
| 版框（p7 类页） | y ≈ 333–1470 @150dpi | 框线在书页弯曲处断裂，直线形态学检测不可靠 → 版框只用于统计，不用于切格 |
| 书眉 | 每版外缘竖排「康熙字典/集名/部首/页码」 | 每页免费真源；OCR 可读（v6 重跑 349+/564 条非空，混内文渗入，T2 做位置感知解析） |
| 页码映射 | 书内页码 = 2×扫描页 − 11（PDF01） | 每册前置页数不同，各自定偏移 |
| 透印残影 | 空白半版常见，灰度 ~180 | BIN_T=150 可干净分离 |

## 3. 50 框金标准（53 框）

- **方法**：检测器出提议框 → 算法紧化（提议框邻域内、与中心重叠的连通域并集 bbox）→

## 5. 结论与 T1 要求

1. **切格可行**：字头（77px 方块、比注文大 2.1 倍）与注文（37px）在高度上分离清晰，
   列内按墨块高度聚类 + 方正度即可分字头；原型已做到零注文误检（目检页）。
2. T1 切格器设计要点：①框必须紧（对金标 IoU≥0.85）；②处理字头-注文纵向近贴
   （间距可小于字高 1/4）；③「一/乚」等横扁/竖扁字头走宽度补偿分支；④补遗页字头
   密度高，防粘连合并。
3. 版面真源链：书眉（集名/部首/页码）→ 部首目录 214 锚点 → 部首/笔画单调性对账。
   OCR（v6+v5 双引擎，冲突率 47.8%）只作先验，不作标签真源。
4. 风险：①框线弯曲段与字头笔画粘连（已用长线剔除缓解）；②补遗/备考体例差异大
   （待 T1 全量时单独调参）；③印章/污渍（邻域密度闸已挡大部分）。

## 7. 页面形变与自动纠偏（2026-11-07 增补，所有者建议参考 vModou）

**来源**：[vModou 兀雨墨斗](https://github.com/shanleiguang/vModou)（MIT，© 2025 ShanLeiGuang）——
古籍刻本扫描图变形纠正工具。思路：辅助线限定搜索区 → 扫描版框四角顶点 → 拉正 → 裁黑边。
本项目**未复制其代码**（Perl/交互式），按其思路用 Python 重实现为自动化流水线步骤，
并在 `docs/VENDORED.md` 记录思想来源。

**实现**（`scripts/t0_rectify.py`）：
1. 版框顶/底 = 强横线（run≥30% 半页宽）按位置取首/末条（**不能按墨量**——页边黑带墨量更大，
   实测选错）；页边黑带清 80px（实测黑带最厚 59px）；
2. 角点 = 横线的**最长连续段端点**（书眉竖排字会污染简单 min/max）；
3. 四点透视拉正为单版图；合理性检查失败（凸性/边长/高度）→ 该半版跳过并记录，绝不硬纠。
4. 探针 4 页 8 个半版 **8/8 纠偏成功**（前后对比图 `work/t00/rect/*_preview.png`）。

**收益量化**（`scripts/t0_rectify_eval.py`，53 金标经同一 H 映射）：

| 半版 | 金标召回 orig→rect | FP orig→rect | 结论 |
|---|---|---|---|
| 01_0110 R（最弯） | **0.25 → 0.625** | 6 → 4 | 纠偏大赚 |
| 13_0163 L | 0.632 → 0.684 | 4 → 8 | 召回升、FP 升 |
| 13_0163 R | 0.545 → 0.455 | 25 → 21 | 互有胜负 |
| 01_0110 L | 0.833 → 0.333 | 0 → 0 | 重采样伤细笔画 |
| matched IoU | 两侧均 0.51–0.57 | — | 瓶颈是框紧度，非形变 |

**结论**：
1. 纠偏修**几何**（栏线垂直度、书眉自动裁除、列记账简单化）——对 T2 部首序对账是真收益；
2. 对**检出**是双刃剑：弯曲重的版大赚，细笔画字头被插值模糊伤（INTER_CUBIC）；
3. **T1 决策**：切格在 20 页上做 orig vs rect 的 A/B，哪边过「IoU≥0.85 占比 ≥85%」门用哪边；
   若走 rect 路线，检出阈值需按拉正图重校（erode 核或改 INTER_LINEAR）。
